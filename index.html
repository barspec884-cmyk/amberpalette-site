Amber Palette

Whiskyを「記録」から「理解」へ。

Amber Paletteとは

Amber Paletteは、ウイスキーのテイスティングを記録し、味覚の探究を深めるためのデジタルプラットフォームです。

色・香り・味わいを精密に可視化し、あなただけの味覚地図を構築します。

主な機能

FEATURE 01

Aroma Balance

香りを、目で見る。

スモーキー、フルーティー、フローラル——感じた香りをタップで積み上げると、その一杯の個性が円環チャートに浮かび上がります。Radar / Profile / Volume の3つの視点で、香りのバランスを多角的に捉えられます。

FEATURE 02

3D Matrix

銘柄を、立体で見比べる。

記録したウイスキーを3D空間に並べて、複数の銘柄を見比べることができます。ドラッグで360°回転、Top / Side / Front の切り替えにも対応しています。

ALSO

Intensity Balance

強さのバランスを、ひと目で。

香りの強さ・厚み・キレ・刺激・締まり・余韻——一杯の印象を6つの軸で採点し、レーダーチャートで可視化します。
